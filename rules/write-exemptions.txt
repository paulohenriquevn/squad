# rule-id: SQ-CFG-09
# Files the Squad produces OUTSIDE `<project>/.squad/`, and what forces each one.
#
# THE RULE THIS FILE IS AN EXCEPTION TO
# -------------------------------------
# Everything this system produces is written under `<project>/.squad/`. One root, so
# the versioning question is answerable and a consumer can delete the dependency
# without deleting its own knowledge. `check_write_containment.py` proves the static
# half (no module outside `squad/paths.py` may spell a data root) and
# `check_produced_files.py` proves the runtime half (nothing appears outside the root
# when the mechanisms actually run).
#
# WHY AN EXEMPTION LIST AND NOT A CLEAN RULE
# ------------------------------------------
# Three kinds of file cannot move, and none of the three is the kit's choice:
#
#   platform   Claude Code DISCOVERS agents and skills by directory. An agent at
#              `.squad/agents/x.md` is not an agent; it is a markdown file nothing
#              can invoke. The location is the interface.
#   tool       An external tool reads its config from a path it chose. Moving
#              `.go-arch-lint.yml` means go-arch-lint stops finding it.
#   human      A file a person opens by name, at the root, by convention older than
#              this kit.
#
# An exemption with no class and no reason is refused by the gate, because "we made
# an exception" and "the platform gave us no choice" are different claims and only
# the second one survives review.
#
# FORMAT
#   <path-glob> | <class> | <what forces it>
#
# Paths are relative to the project root. `<eco>` stands for the installed kit —
# `.claude/` in a plugin install, the project root in a standalone checkout.

<eco>/agents/*.md          | platform | Claude Code resolves a subagent by reading `<eco>/agents/`. `convene_panel.resolve_seat` fails a seat whose file is not there, so a specialist written anywhere else is a seat that cannot be filled
<eco>/skills/*/SKILL.md    | platform | Claude Code discovers skills by directory. `/review` generates one knowledge skill per reviewer per plan and they must be discoverable to be paired with their agent
<eco>/rules/*.txt          | tool     | Allowlists and thresholds a PERSON edits to tune the kit for this project; `install.sh` preserves them across reinstalls. Nothing here is produced by code — the one file that was, `domain-routing.txt`, moved to the write root on 2026-09-10
BACKLOG.md                 | human    | The registry a person opens, at the root, by name. `rules/cycle-backlog.md` fixes the location and every item id in every issue refers to it
ROADMAP.md                 | human    | Hand-authored; no skill generates one. Named here because `/acceptance` WRITES to it — it flips a milestone checkbox
CHANGELOG.md               | human    | Keep a Changelog puts it at the root, and `/release` rewrites its `[Unreleased]` section
.go-arch-lint.yml          | tool     | go-arch-lint reads it from the repository root
.dependency-cruiser.cjs    | tool     | dependency-cruiser reads it from the repository root
.importlinter              | tool     | import-linter reads it from the repository root
.*.lock                    | tool     | The sidecar `squad/shared_file.py` locks while a shared file is read-modify-written. It lives beside its target because `os.replace` on the target would release a lock on an inode nobody holds any more; it carries no content and is never read
