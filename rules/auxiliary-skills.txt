# CONSUMER PROJECT skills that are a phase of no cycle.
#
# This file arrives empty on purpose: the KIT's auxiliary skills live in the
# `AUXILIARY_SKILLS` constant inside `check_xrefs.py`, and they stay there — they
# are the kit's inventory, versioned along with it. What this file adds is the
# extension: a project that wrote its own domain skills declares them here,
# without touching the validator's body.
#
# `check_xrefs.py` warns when a skill is referenced by no cycle-*.md and declares
# no `## Cycle contract`. For the kit's own skills that is a real defect; for a
# domain specialist the project wrote and invokes on demand, it is the design —
# and the warning, repeated, teaches people to ignore the validator.
#
# Before this file the only way out was editing the AUXILIARY_SKILLS constant
# inside check_xrefs.py, and an edit in the validator's body is exactly what the
# kit's next sync overwrites.
#
# Format: one skill directory name per line; `#` comments.
# A name that does not exist on disk is ignored: this is a declaration of intent,
# not an inventory.
