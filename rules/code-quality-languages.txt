# Languages enabled for /code-quality and post-edit-check.sh.
#
# Format:  LANGUAGE | MANIFEST-MARKER | STATUS | NOTES
#
#   LANGUAGE         one of the identifiers listed below
#   MANIFEST-MARKER  path to the manifest, RELATIVE TO THE REPO ROOT. Not cosmetic: it is
#                    what sends each detector to the right directory. The dead-code CLIs
#                    resolve their project from the cwd, so a crate at `theodb_rs/Cargo.toml`
#                    or a package under `web/` must declare it here or the auditor reports
#                    itself unavailable and the cycle stalls on a path assumption.
#   STATUS           ENABLED | DISABLED | DEFER
#   NOTES            free text; optional, but say WHY when a language is DISABLED or DEFER
#
# Lines starting with '#' are comments. Anything with fewer than three '|' fields is a
# hard error, not a warning — a malformed line means a language you believe is audited is
# not, and that is worse than a crash.
#
# Default policy: empty file = no language-specific quality checks run. Each project
# enables the languages it actually uses.
#
# Examples, one per supported language — uncomment and fix the manifest path to match your
# layout. The path shown is the common case, NOT a guess this file makes for you.
#
# go         | go.mod              | ENABLED  | Where the module lives.
# python     | pyproject.toml      | ENABLED  |
# typescript | package.json        | ENABLED  | A monorepo declares the workspace it audits.
# javascript | package.json        | ENABLED  |
# rust       | Cargo.toml          | ENABLED  | Point at the crate, not the workspace root.
# java       | pom.xml             | ENABLED  |
# kotlin     | build.gradle.kts    | ENABLED  |
# ruby       | Gemfile             | ENABLED  |
# csharp     | *.csproj            | ENABLED  |
