# rule-id: SQ-ALW-05
# Tracked paths that may carry Portuguese. Read by `mechanisms/gates/check_english_only.py`.
#
# THE RULE THIS FILE IS AN EXCEPTION TO
# -------------------------------------
# `rules/english-only.md` (SQ-LNG-01): every versioned file is English. The checker
# scores each line for Portuguese evidence instead of matching a closed word list, so
# it no longer needs to be blind to ordinary Portuguese words to stay quiet on the
# files that carry them ON PURPOSE. This file is where that purpose is declared.
#
# WHAT BELONGS HERE
# -----------------
#   - Product copy a project ships in Portuguese: locale files, UI strings.
#   - Test data that must be Portuguese to exercise what it tests — captured
#     Portuguese screens, a consumer's registry text, the input of a Portuguese
#     smell detector.
#
# What does NOT belong here: a file with one Portuguese line. Keep that line with a
# marker on the line itself — `# english-only: <why>` — so the rest of the file is
# still checked. A path listed here is not read at all.
#
# FORMAT
#   <path-glob> | <why this path carries Portuguese>
#
# Paths are relative to the project root and matched with `fnmatch`: `*` crosses `/`,
# so `web/locales/pt-BR/*` covers everything below it. A row with no reason is
# refused and the checker exits 2 — an opt-out that says nothing is the silent
# exception the gate exists to prevent.
#
# The rows below are the kit's own. In a consumer, replace them with the project's.
